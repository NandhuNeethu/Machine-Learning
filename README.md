# Machine-Learning
Machine Learning-based crop recommendation system using soil nutrients and environmental parameters.

## Project Overview

The dataset contains 2,200 records covering 22 different crop types and 7 input parameters:

- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- Soil pH
- Rainfall

Three classification models were developed and evaluated:

- Logistic Regression
- Decision Tree
- Random Forest

Random Forest achieved the best performance with 99.3% accuracy.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Gradio

## Gradio Interface

An interactive Gradio interface was developed to accept soil and environmental parameters and predict the most suitable crop.
